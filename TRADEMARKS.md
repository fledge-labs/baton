# Baton name and logo

The code is free for everyone under Apache-2.0 (see LICENSE). Like Apache-2.0 section 6, this note keeps the name separate from the code license. The name only needs to stay honest:

- You may say your product "uses Baton", "works with Baton" or is "based on Baton".
- You may ship modified versions. If you publish one, give it a name that does not suggest it is the official Baton project, or say clearly that it is modified.
- Do not use the Baton name or logo in a way that implies endorsement by the Baton project.

That is the whole policy. If you are unsure, open an issue and ask.
